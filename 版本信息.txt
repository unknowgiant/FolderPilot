三、本版变更（摘自 更新日志.txt）

  新增
    · 安装向导首屏「版本对比」：蓝色卡片是「即将安装 v1.7」，下面灰色卡片是
      「系统已有 v1.5」，中间用箭头和一句话说清这次是升级、全新安装、同版本
      重装还是降级。已装版本依次从注册表卸载项、install.json、旧版主程序
      文件名三处兜底探测，注册表被清理过也能认出来。
    · exe 右键 → 属性 → 详细信息里能读到文件版本、产品名与公司名（PyInstaller
      版本资源），便携版与安装包都有——这才是「序号放进软件包」的落地点。
    · 版本一致性自检新增硬规则：窗口标题 / exe 名 / 安装包名 / 交付包名 /
      快捷方式名里只要出现数字就报错，防止以后又把序号写回名字里。
  修复
    · 安装向导内容变多后按钮栏被挤出窗口（页面用 expand 抢占全部空间），
      改为按钮栏先贴底、页面再填充剩余区域，窗口 600×430 → 620×648。
    · 「创建桌面快捷方式」复选框在 clam 主题下渲染成 ✕，看着像关闭；换回
      原生复选框，选中即 ☑。
    · 静默安装新增 --no-cleanup：自动化测试装到临时目录时，不再顺手删掉本机
      真实安装的快捷方式与旧版本目录。
  变更
    · 版本号不再标在名称后边：便携版「文件管理多面手.exe」、安装包
      「文件管理多面手-Setup.exe」、交付包「文件管理多面手-交付包.zip」、
      快捷方式「文件管理多面手.lnk」，窗口标题也只叫「文件管理多面手」。
    · GitHub Release 资产名同步去掉版本号（FolderPilot-portable.exe /
      FolderPilot-Setup.exe），版本以 Release 标签区分。
    · 桌面 / 安装目录 / 开始菜单里旧版「文件管理多面手 1.x.exe / .lnk」仍由
      安装器自动清理，不会和新图标堆在一起。
    · 交付包不再收录根目录里带版本号的历史 exe，避免包里塞进上一版。
