一、快速开始（三种方式任选）

  ① 便携版：双击「FolderPilot.exe」直接运行，无需安装。
  ② 安装版：双击「FolderPilot-Setup.exe」→ 按向导安装（用户级，
     免管理员权限），自动创建开始菜单/桌面快捷方式，支持在
     系统「设置 → 应用」中一键卸载。
  ③ 脚本版：双击「启动 FolderPilot.bat」（或直接运行 FolderPilot.pyw，
     前提是系统已关联 Python）。

  依赖：便携版与安装版 EXE 无任何依赖；脚本版需要
  Python 3.10+ 与 pywebview（本机已就绪，换电脑时执行：
      py -3.14 -m pip install pywebview ）。

  提示：启动时若界面短暂空白数秒，是程序在等待/重试应用桥接，
  会自动恢复，无需干预。首次启动会自动释放内置的 Everything64.dll
  到数据目录（Everything 处于运行状态即可秒搜全盘）。

  文件校验（SHA256）：

    FolderPilot-Setup.exe  6826F341C9671CB149FEE10D8B8FE7946D5A7A856891E542AECFA36525C87173

二、功能一览（对照 Pulse）

  1. 多窗格浏览
     · 单栏 / 左右分屏 / 上下分屏 / 三栏 / 四宫格，Ctrl+1~5 切换
     · 每个窗格独立标签页（Ctrl+T 新建 / Ctrl+W 关闭 / 中键关闭）
     · 每个目录记忆自己的视图与排序方式
     · 视图：详情 / 图标（图片自动缩略图）/ 紧凑列表
     · 可拖动布局：侧栏右缘分隔条可拖宽侧栏（140~420px）；详情
       视图列头间手柄可拖调「大小/修改时间/类型」列宽，松手自动
       记忆，重开软件保持

  2. Everything 全盘秒搜
     · 全局呼出：Alt+Space（任何界面）；应用内 Ctrl+F
     · 文件名、路径、通配符、ext: / size: / dm: 语法全部可用
     · 高级筛选：类型、大小、日期（含自定义区间）、内容搜索(content:)、
       区分大小写、全字匹配
     · 结果双击打开，Ctrl+Enter 跳转所在目录，右键更多操作
     · 自动检测：SDK 直连（免配置）→ HTTP 备用 → 本地兜底搜索

  3. 文件操作
      · 复制/剪切/粘贴（Ctrl+C/X/V 全窗口生效，含移动/复制语义
        与资源管理器剪贴板互认，跨软件双向粘贴）
      · 右键属性（大小/创建/修改/访问时间/只读隐藏等属性位）
      · 删除进回收站（Del）、重命名（F2）、新建文件夹（Ctrl+Shift+N）、
        新建文本文档（右键）
      · 窗格间拖拽：默认复制，按住 Shift 移动
      · 同名冲突自动改为「xxx - 副本.ext」，大文件操作带进度条

  4. 空格预览（选中按 Space）
     · 图片 / 视频 / 音频 / PDF（内嵌播放与翻页）
     · 文本、代码（语法高亮）、Markdown（渲染排版）
      · 压缩包：右键压缩为 ZIP / 解压到当前文件夹或指定目录；空格
       预览：目录树 + 包内搜索 + 单项提取 / 全部解压
     · 悬停缩略卡片：鼠标停留即显示摘要（可在设置关闭）

  5. 暂存盘（左下角托盘）
     · 复制/剪切或右键「加入暂存盘」跨目录收集文件
     · 一键「复制/移动到活动窗格」，暂存两个文本文件时可直接对比

  6. 对比
     · 文本 diff：并排/统一视图、忽略空白/大小写、差异跳转
     · 文件夹对比：标记 仅A/仅B/不一致/相同，可递归 3 层，一键互拷

  7. 其他
      · 七色标签：右键标记颜色；侧边栏纵向列出各颜色及数量
      · 收藏夹：侧边栏「固定当前目录」；磁盘显示为容量进度条
      · 面板工具栏右侧「⋯」菜单：新建文件夹、筛选当前目录、
        在终端中打开、与下一窗格对比文件夹（地址栏输入 cmd /
        wt / powershell 也可开终端）
      · 导出 CSV（标签/暂存/收藏/搜索历史，带 BOM）：设置 → 数据
      · 深浅主题：顶栏 ☀/☾ 按钮一键切换（设置页可选 浅色/深色/跟随
        系统）；安装向导右上角也可切换深色模式。紧凑/舒适行高
      · 恢复上次会话；右键空白菜单或「设置 → 数据」可切换管理员
        模式重启（UAC 确认后生效）；右键 exe/msi/bat/cmd 等可执
        行文件可"以管理员身份运行"（UAC 确认）

三、快捷键速查

  Alt+Space        全局呼出搜索          Ctrl+1~5      切换布局
  Ctrl+F           应用内搜索            Ctrl+T / W    新建/关闭标签页
  地址栏搜索钮      当前文件夹内搜索（含子目录，可选类型）
  Space            预览                  F2            重命名
  Del              移入回收站            Ctrl+C/X/V    复制/剪切/粘贴
  Ctrl+Shift+N     新建文件夹            F5            刷新
  Alt+←/→          后退/前进             Backspace     上一级
  鼠标返回键        上一级（侧键，界面任意位置生效）
  Ctrl+A           全选                  Enter         打开
  Ctrl+Shift+C     复制当前目录完整路径（地址栏任意位置右键也可复制）

四、Everything 集成说明

  · 首选 SDK 方式：程序内嵌官方 Everything64.dll，只要 Everything
    在运行即可查询，无需任何设置。
  · 检测到 Everything 1.5 alpha 时自动启用拼音搜索（输入简拼如
    "jsbg" 可匹配 "技术报告"）；1.4 正式版不支持拼音索引，输入
    中文/英文/通配符不受影响。
  · 若 SDK 不可用，自动尝试 Everything 的 HTTP 服务（需在
    Everything 选项中开启 HTTP 服务器），再不可用则退化为从当前
    目录向下逐层搜索的本地兜底模式。
  · 自动启动：检测到 Everything 未运行时，软件会自动查找并启动
    它（读注册表安装信息，找不到时按常见路径与运行中进程兜底），
    稍候数秒自动重连；可在「设置 → 搜索」关闭该行为。状态栏点
    击"Everything 未运行 · 点击自动启动"也可手动触发。
  · 状态栏左下角实时显示连接状态，点击可重连。

五、数据与卸载

  · 全部数据保存在 %APPDATA%\FolderPilot\（config.json 与导出的
    CSV），不写注册表服务项、不留后台进程。
  · 便携版卸载：删除本文件夹 + %APPDATA%\FolderPilot\ 即可。
  · 安装版卸载：系统「设置 → 应用」中找到 FolderPilot 点卸载，
    或运行安装目录内的 FolderPilot-Unins.exe；程序数据目录会
    保留（含收藏/标签/搜索历史），如需彻底清除请一并删除。
  · 单实例运行：重复启动会自动唤起已有窗口。

六、已知限制（如实说明）

  · DOCX/XLSX/PPTX 无内嵌渲染预览（显示元信息，可一键用系统程序
    打开）；检索这些格式的正文可用搜索面板的「内容」选项（由
    Everything 完成，1.4 下速度较慢）。
  · 从资源管理器往本程序拖拽文件受浏览器安全限制不可用，
    请用 Ctrl+C/V 或暂存盘跨应用转移。
  · PSD/DWG 等专业格式显示图标与元信息，不渲染缩略图。
