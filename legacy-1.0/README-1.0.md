# 文件夹全能手（FolderPilot）

Windows 桌面双窗格文件管理器（Python + pywebview 单文件应用）。

- 多窗格浏览（单栏/分屏/三栏/四宫格）、Everything 全盘秒搜、暂存盘中转、空格即时预览、七色标签、文件夹对比、压缩包浏览提取等
- 源码：`FolderPilot.pyw`（单文件应用，界面以资源内嵌）
- 运行：安装 Python 3.10+ 与 `pywebview` 后，双击 `启动 FolderPilot.bat`
- 功能明细见 `使用说明.txt`；内嵌 Everything SDK 的授权见 `licenses/`

> 本仓库为 1.0 旧版源码存档。新版《文件管理多面手》为分层架构重写版，另行维护。
